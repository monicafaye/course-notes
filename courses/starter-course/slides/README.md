# Course Slides Directory

Drop your raw course slide decks (`.pdf`, `.pptx`, etc.) into this `slides/` folder.
Raw slide files in `courses/*/slides/` are ignored by Git (`.gitignore`) so large binary files do not bloat the repository.

## Naming Recommendation
Prefix slide files with their lecture number for automatic 1-to-1 mapping:
- `01-introduction.pdf` -> `../lectures/01-introduction.typ`
- `02-architecture.pdf` -> `../lectures/02-architecture.typ`
